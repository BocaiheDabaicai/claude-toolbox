> 更新日期：YYYY-MM-DD

## 1. 实体

| 实体 | 状态字段 | 说明 |
|---|---|---|
| 订单 | status |  |

## 2. 状态

| 状态 | 含义 | 是否终态 |
|---|---|---|
| pending | 待处理 | 否 |
| active | 生效 | 否 |
| closed | 关闭 | 是 |

## 3. 转换

| 当前 | 动作 | 目标 | 触发方 | 副作用 |
|---|---|---|---|---|
| pending | 支付成功 | active | 支付回调 | 扣库存、写流水 |
| active | 关闭 | closed | 管理员 | 释放库存 |

## 4. 不变量

- 只有 pending 可以支付；
- closed 不可再次流转；
- 金额在流转中不可为负。

## 5. 异常

| 场景 | 处理 |
|---|---|
| 重复回调 | 幂等，返回已有结果 |
| 非法流转 | 拒绝并记录审计日志 |
