# 迁移 Playbook

## 1. 角色

| 角色 | 职责 |
|---|---|
| 迁移负责人 | 计划、排期、风险、切换决策 |
| 业务负责人 | 确认字段语义、验收、签字 |
| DBA | 源/目标库权限、备份、性能、回滚 |
| 开发 | 映射、转换、脚本、应用切换 |
| 测试/验收 | 对账、抽样、主链路验证 |

小项目可以一人多角色，但**签字和回滚责任人**不能省。

## 2. 阶段与门禁

### 阶段 0：范围

输入：

- 源系统、源表/文件；
- 目标库/表；
- 数据量、增量方式；
- 停机窗口；
- 业务主键/唯一键；
- 回滚方式。

出口：`docs/migration-plan.md` 初稿。

### 阶段 1：画像

- 行数、空值、空字符串、去重值；
- 重复键、异常状态、日期/金额范围；
- 样例数据；
- 编码、分隔符、Excel 合并单元格等格式问题。

出口：`docs/profile.md`，异常值有解释。

### 阶段 2：映射

- `mapping.csv` + `transforms.py`；
- `migration-kit plan` 无 ERROR；
- 业务确认字段语义、枚举、默认值、未知值处理。

出口：映射评审通过。

### 阶段 3：Dry-run

- `migration-kit run`（不带 `--apply`）；
- 小批量 `--limit 100`；
- 检查样例、计数、错误、跳过。

出口：dry-run 结果业务确认。

### 阶段 4：首次加载

- 目标库备份；
- `migration-kit run --apply`；
- 记录 processed/written/skipped/errors；
- 失败可续跑。

出口：目标表有数据，错误为 0 或已处理。

### 阶段 5：对账

- 数量、金额、汇总；
- 唯一键/外键/空值；
- 抽样逐字段；
- 差异记录与处理。

出口：`docs/reconcile.md` 通过并签字。

### 阶段 6：切换

- 冻结源写入；
- 最终增量；
- 对账；
- 切换应用；
- 健康检查、主链路验证；
- 观察期。

出口：`docs/cutover-checklist.md` 全部勾选。

### 阶段 7：收尾

- 源库只读保留；
- 清理临时表/脚本；
- 归档画像、映射、对账、切换记录；
- 复盘问题与改进。

## 3. 时间线模板

| 时间 | 动作 | 负责人 |
|---|---|---|
| T-7d | 画像、映射评审 |  |
| T-3d | dry-run、全量预迁移 |  |
| T-1d | 备份、演练回滚 |  |
| T-2h | 通知冻结 |  |
| T-0 | 最终增量、对账、切换 |  |
| T+2h | 主链路验证 |  |
| T+24h | 观察与遗留问题 |  |
| T+72h | 确认下线源系统 |  |

## 4. 沟通

- 切换前发通知：时间、影响、联系人；
- 切换中在群里同步每一步；
- 异常时先止血/回滚，再分析；
- 切换后发结果与遗留问题。
